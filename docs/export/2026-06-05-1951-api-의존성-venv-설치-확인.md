## 핵심: 워크스페이스 멤버는 editable로 연결

`site-packages`에 `.pth` 파일로 각 멤버가 소스 디렉터리에 직접 링크돼 있습니다:

```
_editable_impl_api.pth        _editable_impl_rag.pth
_editable_impl_eval.pth       _editable_impl_pipelines.pth
_editable_impl_finetune.pth   _editable_impl_ftdata.pth
```

- `rag`·`api` 등은 복사본이 아니라 `packages/rag/src`·`apps/api/src`를 **그대로 가리키는 editable 설치**라, 소스 수정이 즉시 반영됩니다.
- 그래서 `apps/api`가 의존하는 `rag = { workspace = true }`도 별도 설치 없이 동작합니다.

즉, **`apps/api`의 모든 런타임·개발 의존성이 루트 `.venv`에 갖춰져 있고**, 워크스페이스 멤버 6개(api/rag/eval/finetune/ftdata/pipelines)가 editable로 연결돼 정상 동기화된 상태입니다.

> 참고: 배포 문서([02 Linux GPU](docs/superpowers/release/02-linux-gpu.md))의 컨테이너 빌드에서는 이 단일 `.venv`를 그대로 쓰지 않고, 이미지에서 `uv sync --package api`로 **api에 필요한 멤버만** 골라 설치하는 것을 전제로 했습니다(개발용 통합 `.venv`와 배포 이미지의 분리).
