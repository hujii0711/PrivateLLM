## 함께 권장: 팀 공유용 `.vscode/` 구성

`.vscode/`가 없으니, **레포에 추천 확장 + 워크스페이스 설정을 커밋**해 두면 누가 클론해도 동일 환경이 됩니다. 핵심은 두 가지:

1. **`.vscode/extensions.json`** — 위 확장을 "권장"으로 등록(클론 시 설치 팝업).
2. **`.vscode/settings.json`** — uv 단일 `.venv` 인터프리터 지정 + Ruff를 파이썬 기본 포매터로 + 저장 시 포맷/정리.

```jsonc
// .vscode/settings.json (핵심만)
{
  "python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python",
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": { "source.organizeImports": "explicit" }
  },
  "eslint.workingDirectories": [{ "directory": "apps/web", "changeProcessCWD": true }],
  "search.exclude": { "**/.venv": true, "**/node_modules": true, "**/data": true, "**/__pycache__": true }
}
```

> 주의: Ruff를 도입하면 lint 규칙이 생기므로, 기존 코드에 경고가 뜰 수 있습니다. `pyproject.toml`에 `[tool.ruff]` 최소 설정(line-length, target py311)을 같이 두는 걸 권장합니다.

## ⚠️ 기존 코드 영향 — 미리 알아두세요

새 Ruff 규칙으로 기존 코드에 **41건**이 잡힙니다(대부분 경미, 27건 자동수정 가능):

| 종류 | 건수 | 자동수정 |
|---|---|---|
| `I001` 임포트 정렬 | 16 | ✅ |
| `UP035` 구식 임포트(`typing.List` 등) | 7 | ✅ |
| `E501` 줄 길이 초과 | 4 | ❌ 수동 |
| `B905` `zip(...)` strict 누락 | 3 | ❌ |
| `E731` 람다 대입 | 3 | ❌ |
| 기타(E741·F401·UP045 등) | 8 | 일부 ✅ |

저장 시 자동수정(`source.fixAll.ruff`)을 켜뒀기 때문에, **파일을 열어 저장하면 임포트 정렬·구식 임포트 등이 자동으로 바뀝니다**. 갑작스러운 대량 diff를 원치 않으시면:

- **일괄 정리**: `uvx ruff check --fix packages apps pipelines && uvx ruff format packages apps pipelines` 를 한 번 돌려 별도 커밋으로 분리(권장 — 리뷰 깔끔).
- **점진 적용**: 그대로 두고 건드리는 파일만 저장 시 정리.
- **자동수정 끄기**: 원하면 settings.json의 `source.fixAll.ruff`/`organizeImports.ruff`를 제거해 수동 린트만.

어떻게 정리할지 알려주시면, 원하시는 방식(일괄 정리 + 별도 커밋 등)으로 진행하겠습니다. 이 세 파일과 Ruff 정리 결과는 아직 커밋하지 않았습니다 — 커밋도 원하시면 함께 처리하겠습니다.
