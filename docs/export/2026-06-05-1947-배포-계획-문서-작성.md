## 핵심 설계 포인트

- **하나의 코드베이스, 세 배포**: 이미 존재하는 `LLM` Protocol 덕에 환경별로 백엔드 구현 1개(`MlxLLM` vs `OpenAICompatLLM`)만 바뀌고 검색·프롬프트·인용·면책·감사 경로는 100% 동일합니다.
- **운영 모델은 어댑터 없는 순수 RAG 베이스라인** — A/B 음성 결과를 반영(어댑터 경로는 config 옵션으로만 유지).
- **법률 도메인 PII**: 수집 단계 마스킹 + 감사 저장소 분리 + 보관기간/접근통제를 공통 하드닝에 명시.
- **권장 환경은 Linux GPU** — vLLM 연속 배칭이 중규모 동시성을 가장 깔끔하게 흡수합니다.
