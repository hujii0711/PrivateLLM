### 전체 데이터 흐름

```
chunks.jsonl
     │ (64개씩 배치)
     ▼
Embedder.embed(texts)
  └── BAAI/bge-m3 (SentenceTransformer)
       normalize_embeddings=True
     │
     ▼ (1024차원 벡터)
ChromaDB.upsert()
  ├── id          — 청크 고유 ID
  ├── documents   — 원문 텍스트
  ├── embeddings  — 임베딩 벡터
  └── metadatas   — source_type, title, ref, url, date
```

### 모델 선택: `BAAI/bge-m3`

| 항목 | 내용 |
|------|------|
| **모델** | `BAAI/bge-m3` |
| **출력 차원** | **1024차원** (테스트에서 검증됨) |
| **정규화** | `normalize_embeddings=True` — 코사인 유사도에 바로 쓸 수 있게 L2 정규화 |
| **선택 근거** | 한국어·영어·중국어 다국어 지원 + 법률 도메인 문장 수준 임베딩에 강점 |

### 디바이스 최적화: 지연 로딩 + MPS

```python
# macOS Apple Silicon이면 MPS GPU 사용, 아니면 CPU
device = "mps" if torch.backends.mps.is_available() else "cpu"
self._model = SentenceTransformer(self._model_name, device=device)
```

- 모델은 `embed()` 첫 호출 시 **지연 로딩(Lazy Loading)** — 불필요한 초기화 비용 제거
- `mps` 디바이스로 **Apple Silicon GPU 가속** 자동 활성화

### 배치 처리 전략

```python
_BATCH = 64  # 64개씩 묶어서 처리

for i in range(0, len(chunks), _BATCH):
    batch = chunks[i : i + _BATCH]
    embeddings = embedder.embed([c["text"] for c in batch])
    col.upsert(...)
```

- **64개 단위 배치** — 모델 추론 효율 + 메모리 사용량 균형
- 한 번에 전체를 처리하지 않아 대용량 데이터에서도 OOM 방지

### 벡터 DB: Chroma + 코사인 유사도

```python
col = client.get_or_create_collection(
    COLLECTION,                          # "jeonse_deposit"
    metadata={"hnsw:space": "cosine"}   # 코사인 거리 사용
)
```

| 항목 | 내용 |
|------|------|
| **DB** | ChromaDB (로컬 영속 저장) |
| **알고리즘** | HNSW (Hierarchical Navigable Small World) |
| **유사도** | `cosine` — normalize된 벡터와 짝을 이루는 올바른 설정 |
| **저장 방식** | `upsert` — 재실행 시 중복 없이 갱신 (멱등성 보장) |

### 테스트 가능성 설계: `encode_fn` 주입

```python
# 운영: 실제 bge-m3 모델 사용
embedder = Embedder()

# 테스트: 가짜 함수 주입 → 모델 없이 동작 검증
embedder = Embedder(encode_fn=lambda texts: [[1.0, 0.0] for _ in texts])
```

무거운 모델 다운로드 없이 테스트할 수 있도록 `encode_fn`을 외부에서 주입 가능하게 설계한 것이 핵심입니다. 실제 bge-m3 테스트는 `@pytest.mark.slow`로 분리되어 선택적으로 실행됩니다.

### 청킹 → 임베딩 전략 전체 연결 요약

```
법령/판례 JSON
  → chunk_law() / chunk_prec()  ← 구조 인지 청킹
  → normalize_text()            ← 공백·특수문자 정제
  → chunks.jsonl 저장
  → Embedder(bge-m3)            ← 64개 배치 임베딩
  → ChromaDB upsert             ← cosine HNSW 색인
```
